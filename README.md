# LevelUp — Solo Leveling System HUD

A real-life gamification HUD inspired by the "System" interface from *Solo Leveling*. Available as a **Standalone Desktop Executable App**, a **Shareable ZIP Package**, and a **Web Application**.

---

## 1. Standalone Desktop App (ZIP Package)

- **File Path**: [LevelUp_v1.zip](file:///c:/Users/Zareen%20Ansari/OneDrive/Desktop/SL%20meta/system_ar_glasses/LevelUp_v1.zip)
- **Share with anyone on Windows**: Unzip `LevelUp_v1.zip` and double-click `LevelUp.exe`. No Python or setup required!

---

## 2. Web Application (`web_app/`)

- **Folder Path**: [web_app/](file:///c:/Users/Zareen%20Ansari/OneDrive/Desktop/SL%20meta/system_ar_glasses/web_app/)
- **Run Locally**: Double-click `web_app/index.html` to open in any web browser (Chrome, Edge, Safari, Firefox).
- **Deploy Online**: Upload the `web_app/` folder to Vercel, Netlify, or GitHub Pages for free online hosting!

### Web App Features
- **Solo Leveling AR Aesthetics**: Dark violet (`#1A0B2E`) glassmorphism with glowing neon cyan (`#00E5FF`) and Google Fonts (`Outfit` & `Inter`).
- **Web Speech API**: Synthetic System Voice TTS and browser Microphone Voice Command recognition.
- **Hunter Registration & Add Quest Form**: Startup registration prompt and interactive quest creation modal.
- **`localStorage` Persistence**: Automatically saves your player level, stats, and custom quests across browser sessions.
- **Responsive Viewports**: Switch between Desktop (`1000px`) and Mobile (`440px`) modes on the fly.
